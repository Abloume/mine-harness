# 文件操作安全规范

执行任何文件操作（read / write / delete / rename）前，必须遵守以下规则：

1. 删除或覆盖文件前，必须先调用 `backup` 工具把文件备份到 `backup/` 目录；
2. 备份失败则停止操作并汇报，不得强行继续；
3. 涉及 delete 的动作，执行前向用户说明原因（审批由 harness 自动处理时，配合其流程说明）；
4. 汇报结果时说明"已备份 / 未备份"，便于用户核验。

违反以上任一规则视为违规操作。
