# 删除/覆盖前检查清单

本文件是 `file-ops-policy` 技能的附属资源（L3 按需引用），由 SKILL.md 正文第 2 条规则触发读取。

执行删除（delete）或覆盖（write/rename 覆盖已有文件）前，逐项核对以下清单，全部通过才可继续：

1. 目标文件已通过 `backup` 工具备份到 `backup/` 目录，且备份返回成功；
2. 目标路径不是系统关键文件（配置目录、家目录根、项目根 `.git` 等）；
3. 已向用户说明删除原因（在审批流程中配合说明）；
4. 若目标文件不存在，停止操作并汇报，不得假装成功。

任意一项未通过：停止操作，汇报原因，等待用户指示。
